# JPG → PNG 本地批量转换器

一个完全在本机运行的 JPG 转 PNG 小工具。支持一次选择多张图片，可指定每张输出文件的最大大小，并把结果打包成 ZIP 下载。

## 功能

- 仅接受 JPG/JPEG 输入，输出标准 PNG
- 支持一次选择或拖入最多 20 张图片
- 可设置每张输出文件必须小于指定 MB
- 批量逐张转换，单张失败不会中断整批任务
- 显示每张图片的转换状态、输出大小和尺寸
- 支持逐张下载或一次性下载 ZIP
- 转换和文件处理全部在本机完成，不会上传到第三方服务器
- 支持 Windows、macOS 和 Linux

## 直接使用（Windows）

双击：

```text
启动图片转换器.bat
```

首次运行会自动打开浏览器。以后需要先双击该文件启动服务。

## 手动启动

```powershell
npm install
npm start
```

然后打开：

```text
http://127.0.0.1:5174
```

## 批量限制

- 每批最多 20 张图片
- 单张 JPG 最大 50 MB
- 每批输入图片总大小最大 200 MB
- 整批预计输出总大小最多 500 MB
- 大小上限应用到批次中的每一张图片

## 目标大小如何实现

PNG 是无损格式，没有 JPEG 那种“质量百分比”参数。为了满足文件大小上限，工具依次尝试：

1. 保持原分辨率，生成最多 256 色的 PNG
2. 保留原分辨率，减少调色板颜色数量
3. 调整分辨率，优先保留尽可能高的像素尺寸和 128 色调色板
4. 如果目标仍无法达到，会明确提示失败，而不是输出超过上限的文件

界面中的 1 MB 按 `1,000,000` 字节计算，适合常见上传限制的“小于 1 MB”要求。
